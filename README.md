Calculadora JavaScript

Projeto desenvolvido para praticar manipulação de DOM, eventos e lógica matemática utilizando JavaScript puro.

🚀 Funcionalidades
Operações matemáticas básicas
Eventos de teclado (Enter e Backspace)
Histórico lateral dinâmico
Layout responsivo
Interface moderna com CSS

🛠 Tecnologias utilizadas
HTML5
CSS3
JavaScript (ES6)

📱 Responsividade
O layout se adapta para desktop e dispositivos móveis.

🎯 Objetivo
Projeto criado com foco em aprimorar conhecimentos em:

Manipulação de DOM

Programação Orientada a Objetos

Estruturação de código
